## 🎯 Overview & Problem Statement
Forward and analytical inverse kinematics for a 3-DOF articulated planar robotic arm, executing cubic polynomial joint space trajectory planning with end-effector Cartesian tracking.

This repository provides verified, modular MATLAB source code and analytical formulas designed for university research, ABET/CEAB engineering labs, capstone design, and industrial modeling.

---

## 📐 Mathematical Formulation & Governing Equations

- **Forward Kinematics Position Mapping:**
  $$x_e = L_1 \cos\theta_1 + L_2 \cos(\theta_1 + \theta_2) + L_3 \cos(\theta_1 + \theta_2 + \theta_3)$$
  $$y_e = L_1 \sin\theta_1 + L_2 \sin(\theta_1 + \theta_2) + L_3 \sin(\theta_1 + \theta_2 + \theta_3)$$
- **Jacobian Velocity Equation:**
  $$\dot{X}_e = J(\Theta) \dot{\Theta}$$

## 🚀 Quickstart & Execution

### Prerequisites
- MATLAB R2022b, R2023b, R2024a, or R2024b
- Base MATLAB (Zero paid proprietary third-party toolboxes required for this starter script)

### Running the Benchmark Simulation
1. Clone this repository:
   ```bash
   git clone https://github.com/matlabsolutions-simulink/robot-manipulator-inverse-kinematics-simscape.git
   cd robot-manipulator-inverse-kinematics-simscape
   ```
2. Open MATLAB and navigate to the project directory.
3. Run the primary entry script in the MATLAB Command Window:
   ```matlab
   run_robot_manipulator_ik
   ```
